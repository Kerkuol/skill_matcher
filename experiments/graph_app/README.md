# Графовый прототип: навыки без оценки уровня

Отдельная точка запуска с собственной копией матриц. Основное приложение и
прототип используют один пакет `skill_graph`; рабочая база не заменяется тестовой.

## Запуск

Из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m streamlit run experiments/graph_app/app.py --server.port 8502 --server.address 127.0.0.1 --server.headless true --browser.gatherUsageStats false
```

Адрес: http://127.0.0.1:8502/?view=analysis

## Изменения

- Блок результатов упрощён: шесть карточек, вкладки «Визуализация», «Навыки», «Рекомендации» и граф непосредственно под ними. Во вкладке визуализации остались кольцевая и радарная диаграммы. Отдельная техническая таблица, выбор требования и подробный разбор путей из основного экрана убраны; фрагменты доступны во вкладке навыков и при нажатии на узел.
- При нескольких резюме автоматически открывается сравнение: рейтинг по соответствию, карта подтверждений каждого требования и выбор кандидата. Ниже показываются только его результаты и граф. Выбор не запускает повторную обработку; идентификаторы включают номер файла, поэтому одинаковые имена не конфликтуют.
- Граф оформлен как светлые созвездия: жёлтые центры подтверждённых навыков, серые неподтверждённых, графитовые связи и плавное движение. Поддерживается системное уменьшение анимации. В графе можно отключить ассоциации, менять масштаб и читать полную подпись/цитату нажатием на узел.

- Уровень владения и грейд не оцениваются. Колонки и карточка уровня убраны из результатов, сравнения и отдельного редактора матриц.
- Старое поле уровня в копии базы сохраняется только для совместимости хранения; на оценку не влияет. Новые строки получают служебное значение без выбора пользователя.
- Личная практика даёт 100% за требование, участие 35%, заявление 20%. Остальное, включая одну ассоциацию, даёт 0%. Итог — среднее по всем требованиям. Коэффициенты экспериментальные.
- Обе тестовые версии резюме инженера данных дают 100% на матрице «Тест графа: инженер данных».
- «Нужно уточнить» заменяет «Требуют развития», «Не подтверждены» заменяет «Отсутствуют». Эти результаты и подписи используются также в основной версии.
- Рекомендации перечисляют требования без описания личной практики, включая только заявления и участие. Неподдерживаемые требования вынесены отдельно: это ограничение механизма, а не пробел кандидата.
- Сеть показывает требования, понятия и фрагменты резюме. Есть физическая раскладка, перемещение узлов, масштаб, панорамирование, подсветка группы навыка и полная цитата по нажатию. Пунктир — тематические связи без баллов. Показаны до двух свидетельств и четырёх признаков на свидетельство. Полный набор требований доступен во вкладке «Навыки».
- Canvas и вся логика находятся в локальном HTML-компоненте. Нет CDN, новых библиотек, API и языковых моделей.

Матрицы прототипа хранятся в `experiments/graph_app/data/matrices.sqlite3`: при первом запуске создаётся копия рабочих и добавляются тестовые. Изменения не синхронизируются обратно. Логи и временные файлы находятся в папке прототипа. История и загруженные файлы хранятся в отдельной Streamlit-сессии.

PDF, DOCX, TXT, пакетная загрузка и смена матрицы поддерживаются. Сканам без текстового слоя нужен OCR, которого здесь нет. Ошибки V3 на цитатах, отдельных отрицаниях и исполнителях остаются; отсутствие подтверждения не доказывает отсутствие навыка. Прототип не обучается на загрузках.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s experiments/graph_app -p 'test_*.py' -v
```

`build_app.py` обновляет точку входа из корневого приложения, сохраняя отдельную
инициализацию прототипа. При обычном запуске пересборка не выполняется.
PDF для автоматических проверок находятся в `tests/fixtures/resumes/`;
все сведения в этих документах вымышлены.

Текущая проверка: 12 тестов прошли, включая переключение кандидата и проверку смены графа без повторной обработки. Отрисовка графа проверена в браузере на матрицах с 5 и 22 требованиями. Механизм оценки этим изменением интерфейса не менялся.
