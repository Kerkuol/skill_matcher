# Skill Matcher

Локальный первичный скрининг резюме по матрицам компетенций в Streamlit.
Поддерживаются PDF с текстовым слоем, DOCX и TXT, одиночная и пакетная загрузка,
создание, копирование и редактирование матриц с сохранением в SQLite.

## Запуск

Из папки проекта, в виртуальном окружении проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

Проверено на Python 3.11.9. В существующем окружении достаточно последней команды. При запуске приложение
использует локальный граф знаний. Загрузок нейросетей, API и ключей не требуется.
Для сканированных PDF без текстового слоя нужен отдельный OCR.

## Оценка и результаты

Требования матрицы связываются с понятиями в `skill_graph/knowledge.json`.
Механизм выделяет известные выражения, проверяет контекст и исполнителя,
составляет свидетельства практики из действий и объектов. В результате
сохраняются точные фрагменты резюме и пути распознавания.

Все строки требований равнозначны:

| Основание | Балл за требование |
|---|---:|
| Описание личной практики | 100% |
| Участие в общей работе | 35% |
| Только заявление навыка | 20% |
| Только ассоциация, обучение, планы, отрицание, чужое действие, отсутствие свидетельств | 0% |
| Неподдерживаемое требование | 0%, остаётся в знаменателе |

Итог — средний балл по требованиям. Это экспериментальная оценка покрытия
резюме свидетельствами, а не вероятность квалификации. Уровень владения
и грейд не оцениваются; старые значения уровня в базе сохраняются для
совместимости и не влияют на процент.

В интерфейсе: шесть карточек, вкладки с диаграммами, навыками и неподтверждёнными
требованиями, затем интерактивный граф. Жёлтые центры обозначают подтверждённые
навыки, серые — отсутствие подтверждения. При выборе навыка раскрываются
основания и цитаты. Пунктир между навыками означает смысловую связь из графа,
она сама по себе не подтверждает опыт и баллов не добавляет. Есть масштаб,
перемещение узлов, плавные анимации и поддержка уменьшения движения в системе.

При нескольких резюме доступны рейтинг, карта сравнения навыков и выбор
кандидата. Его граф и результаты переключаются без повторной обработки файлов.
Кеш учитывает содержимое файлов, ревизию матрицы и версию механизма.

## Матрицы и хранение

Рабочая библиотека — `data/matrices.sqlite3`. Первое открытие пустой базы
добавляет шаблоны из `profiles.py`. При обновлении приложения существующие
матрицы сохраняются. Матрицы прототипа не копируются в рабочую базу автоматически.
История и загруженные резюме хранятся в Streamlit-сессии, не в SQLite.

На Streamlit Community Cloud локальный диск не является постоянным хранилищем:
после пересоздания окружения пользовательская SQLite-база может быть потеряна.
Для постоянной общей библиотеки потребуется внешнее хранилище. Здесь сохранена
прежняя модель локального сохранения.

## Деплой в Streamlit Cloud

Точка входа — `app.py`, зависимости — корневой `requirements.txt`.
В репозитории должны присутствовать `skill_graph/` целиком, включая JSON и HTML,
модули парсера, матриц, навигации, `analytics_charts.py`, `ui_theme.py`,
каталог `styles/` со шрифтами и иконка приложения. Исследовательские скрипты,
PDF-примеры и `experiments/` для запуска основного приложения не нужны.
Тяжёлые зависимости прежнего алгоритма удалены из основного списка.
`extract_skills.py` и `compare_skills.py` оставлены как прежний код, приложение
их больше не импортирует.

Изменения в рабочей копии сами по себе не публикуются. Для обновления облачного
приложения требуется push в ветку, выбранную в настройках его деплоя.

## Проверка и отдельный прототип

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p 'test_*.py' -v
.\.venv\Scripts\python.exe -m unittest discover -s experiments/graph_app -p 'test_*.py' -v
.\.venv\Scripts\python.exe -m streamlit run experiments/graph_app/app.py --server.port 8502
```

Прототип использует тот же пакет `skill_graph`, но свою копию библиотеки в
`experiments/graph_app/data/`. Точка входа прототипа обновляется явным запуском
`experiments/graph_app/build_app.py`. Исследовательские V2/V3 в других папках
сохранены для сравнения, но не являются зависимостями основного приложения.

Граф и словесные соответствия задаются вручную. Произвольные неизвестные
формулировки могут быть пропущены; некоторые отрицания и цитаты чужого опыта
могут быть распознаны неверно. Неподдерживаемые требования отдельно помечаются
для ручной проверки. Отсутствие свидетельства в тексте не доказывает отсутствие
навыка у человека. Перед кадровым решением нужна проверка опыта на интервью.
