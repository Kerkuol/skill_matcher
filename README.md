# AI Skill Matcher
**AI Skill Matcher** — аналитическая система для оценки соответствия резюме заданному профессиональному профилю в области искусственного интеллекта, машинного обучения и смежных дисциплин. Приложение автоматически извлекает технические навыки, сопоставляет их с профилем, рассчитывает уровень соответствия и предоставляет визуальный и текстовый анализ, включая рекомендации по развитию.
**Ссылка на развёрнутое приложение:** https://kerkuol-skill-matcher-app-cljb9e.streamlit.app/

---

## Основной функционал
- Загрузка и обработка резюме в форматах `.pdf`, `.docx`, `.txt`
- Извлечение навыков с определением уровня владения и уверенностью
- Сравнение с профилем компетенций и расчет процента соответствия
- Категориальный анализ и визуализация результатов
- Сравнение нескольких кандидатов по ключевым метрикам
- Встроенный редактор профилей и матриц компетенций (в разработке)

## Установка
1. Клонировать репозиторий:
   
```bash
git clone https://github.com/your_username/ai-skill-matcher.git
cd ai-skill-matcher
```
   
2. Создать и активировать виртуальное окружение:
```bash
   python -m venv venv
   source venv/bin/activate          # для Linux/macOS
   venv\Scripts\activate.bat         # для Windows
```
   
3. Установить зависимости:
```bash
   pip install -r requirements.txt
```
4. Запустить приложение:
```bash
   streamlit run app.py
```
## Использование
1. Выбрать профиль для анализа (например, "Аналитик данных")
2. Загрузить одно или несколько резюме в поддерживаемых форматах
3. Просмотреть результаты анализа:
   - Общий процент соответствия
   - Уровень кандидата
   - Категориальный анализ навыков
   - Список недостающих и рекомендованных для развития навыков
4. Ознакомиться с визуализациями и метриками
5. Использовать редактор профиля для настройки компетенций

## Локальные матрицы компетенций
В разделе «Настройки» доступны «Создать матрицу», «Копировать матрицу» и
кнопка редактирования. Матрица сохраняется только после нажатия
«Сохранить изменения»; «Отменить» отбрасывает черновик. Пока редактор открыт,
выбор профиля заблокирован, чтобы не сохранить изменения в другую матрицу.

Матрицы хранятся в `data/matrices.sqlite3` внутри проекта. При первом запуске
база заполняется исходными профилями без изменения их требований. Для резервной
копии локальных матриц сохраняйте этот файл при остановленном приложении.
Это локальное хранение, а не постоянное внешнее хранилище для облачного деплоя.
Файл базы и окружение разработки исключены из Git.

Проверка: `python -m unittest discover -s tests -v`. Минимальное окружение для
тестов описано в `tests/requirements.txt`. Тесты редактора используют Streamlit
1.32.0 и запускают только существующий блок редактора без ML-моделей.

## Экраны и навигация
- Главная (`?view=home`, также адрес без параметров): лендинг и переходы в работу.
- Анализ резюме (`?view=analysis`): выбор активной матрицы, загрузка файлов,
  прежние результаты, сравнение кандидатов и история.
- Настройки (`?view=settings`): создание, копирование и редактирование матриц.
  Выбор матрицы для редактирования не переключает активную матрицу анализа.

Навигация реализована на Streamlit 1.32 через `st.query_params` и боковое меню,
без дополнительных серверов и frontend-сборки. Прямые ссылки работают на том же
адресе Streamlit Cloud. `navigation.py` отвечает за переходы, `matrix_editor.py`
содержит перенесённый редактор; алгоритм оценки остаётся в `app.py` без изменений.

Резюме, результаты и несохранённый черновик сохраняются в памяти текущей сессии
при переходах через меню и кнопки приложения. После окончания сессии они не
гарантируются. При возврате используются уже рассчитанные результаты; смена
активной матрицы или её сохранённой версии запускает оценку по новым требованиям.
Модели инициализируются только при анализе файлов, а не при открытии лендинга.

## Оформление
Редактор матриц по умолчанию открывает карточку отдельной компетенции; переключатель
«Карточки / Таблица» сохраняет изменения черновика при смене режима. Табличный режим
предназначен для массовых правок, стеклянный обзор и предпросмотр показывают все
требования. Удаление компетенции применяется к сохранённой матрице только после
нажатия «Сохранить изменения»; отмена восстанавливает сохранённую версию.

Светлая тема настроена в `.streamlit/config.toml`; CSS и локальные шрифты находятся
в `styles/`, подключение и оформление графиков — в `ui_theme.py`. Дизайн основан
на приложенном референсе: кремовый фон, чёрные рамки, жёлтый акцент. Для кириллицы
используется Inter из разрешённых в референсе замен, с лицензией OFL в проекте.
Для Streamlit Cloud не нужна отдельная frontend-сборка или дополнительные пакеты:
публикуются обычный `app.py`, существующий `requirements.txt` и файлы оформления.
